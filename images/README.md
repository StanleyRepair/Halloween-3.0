# Grafiki przebrań

Tutaj trafiają grafiki używane przez automat.

Format pliku w `costumes.txt`:

`Nazwa|emoji|opis|typ|plik.png`

Piąte pole jest opcjonalne. Jeżeli jest puste, strona użyje emoji jako zastępczej grafiki.

Przykład:

`Batman|🦇🦸|Mroczny rycerz Gotham.|hero|batman.webp`

Po dodaniu grafiki do tego katalogu i wpisaniu jej nazwy w `costumes.txt`, automat użyje jej zamiast emoji.
